What Is a Debit Note? (And How It Differs from a Credit Note)

Invoicing · Free BizDoc · Nov 25, 2026

A debit note flags that an additional amount is owed beyond what’s already been invoiced — or formally requests a credit from a supplier. It’s the mirror image of a credit note. Here is how it works.

What a debit note is

A debit note is a document that increases the amount owed on a transaction, or notifies a supplier that you’re debiting your account with them. It records an adjustment — an undercharge, a return to a supplier, or extra goods — so both sides’ books agree.

When it's used

  • A supplier undercharged and needs to bill the difference
  • A buyer returns goods to a supplier and raises a debit note against them
  • Extra quantities or charges need documenting after the original invoice

Debit note vs credit note

They’re opposites. A credit note reduces what’s owed (a refund, an overcharge corrected); a debit note increases it (an undercharge, extra owed). Which one you issue depends on whether the adjustment is in the customer’s favour or against it.

Debit note vs invoice

An invoice is the original request for payment; a debit note adjusts an existing transaction. In some trades a supplier simply issues a supplementary invoice instead of a debit note for an undercharge — the effect is similar. Either way, reference the original invoice so the adjustment is traceable.

Frequently asked questions

What is a debit note?

A document that indicates an additional amount is owed on a transaction, or that a buyer is debiting a supplier's account &mdash; for example after an undercharge or a return of goods to the supplier.

What's the difference between a debit note and a credit note?

A credit note reduces the amount owed (a refund or corrected overcharge); a debit note increases it (an undercharge or extra owed). They're opposite adjustments to a transaction.

Is a debit note the same as an invoice?

No. An invoice is the original request for payment; a debit note adjusts an existing transaction. Some suppliers issue a supplementary invoice instead. Reference the original invoice either way.
